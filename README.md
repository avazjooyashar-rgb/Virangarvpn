## 💳 پرداخت

ربات قابلیت دو روش پرداخت را دارد:

### 1. کارت به کارت

کاربر:

خرید VPN
→ انتخاب پلن
→ مشاهده شماره کارت
→ انتقال وجه
→ ارسال رسید

سپس درخواست برای ادمین ارسال می‌شود.

ادمین می‌تواند:

- ✅ تأیید پرداخت
- ❌ رد پرداخت

را انجام دهد.

بعد از تأیید، سرویس VPN ساخته می‌شود.

---

### 2. پرداخت آنلاین

کاربر:

خرید VPN
→ انتخاب پلن
→ پرداخت آنلاین
→ بازگشت به ربات
→ تأیید خودکار پرداخت
→ ساخت سرویس در PasarGuard
→ ارسال کانفیگ
